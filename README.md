# MONPERKS

优惠聚合 + 品牌发现 + Monad 奖励平台的可运行演示与接入工程。

## 快速运行

需要 Node.js 24+。新增测试网模块使用 ethers；请先安装固定依赖并构建。

```sh
npm ci
npm run setup:testnet
npm run build
npm run dev
```

打开 http://localhost:4173 。前端也可直接部署 `dist/` 到静态托管。

开发验证：

```sh
npm ci
npm run check
npm test
node scripts/compile-contracts.mjs
npm run build
```

## 已实现

### 本轮补齐：全栈测试网闭环

- `#launch`：钱包逐笔确认的测试代币/奖励合约部署、充值及启用，保存待确认交易哈希以恢复进度。
- `#testnet`：绑定域名、nonce、时效及浏览器会话的钱包签名登录，服务端测试积分、幂等预留、EIP-712 凭证、链上领取与事件对账。
- 过期未领凭证只有在 finalized 状态核验后才释放积分，不因客户端自报结果加分或退款。
- `#shared`：SQLite 共享社区，签名身份发帖、评论、投票、作者撤回、举报和基础管理员下架接口。
- 本地 Cancun EVM 已实际执行代币与奖励合约部署、充值、领取、事件核验、重复/篡改拒绝及过期安全释放。

完整步骤见 [TESTNET.md](TESTNET.md)。MPRK 无现金价值，不是 USDT。实际 Monad 部署需用户钱包确认；GitHub Pages 不托管 Node 后端。

### 原有离线演示

本轮重点：信息流与社区互动。进入 `#feed` 查看社区动态，`#brands` 查看品牌广场，`#dashboard` 查看我的工作台，`#settings` 编辑本机个人资料。

- 三栏社区信息流：推荐、最新、关注、收藏，支持话题筛选、全文搜索与加载更多。
- 本机动态发布/编辑/撤回/恢复、关联优惠卡片、HTTPS 来源链接与分享定位。
- 实用投票、讨论收藏、评论及撤回、举报隐藏与恢复。
- 品牌关注与相关讨论筛选、个人空间、通知已读、资料编辑及本机数据导出。
- 互动仅保存在此设备；没有模拟他人实时回复，不因互动发放可提现积分。

- 响应式优惠商城：9 个示例优惠，搜索、6 类筛选、积分/品牌排序、分页展示。
- 优惠详情、示例码复制、商家官网跳转、收藏与取消收藏。
- 每日签到、品牌偏好调研、可跳过的 8 秒品牌内容演示。
- 可兑换积分与不可提现发现星独立记录。
- 积分钱包、整数兑换校验、二次确认、余额扣减、兑换历史。
- 浏览器 EIP-1193 钱包连接、账户切换响应、Monad Testnet 添加与切网；不请求签名或授权。
- 底部 5 个社媒图标；配置链接后直接跳转，无配置时显示待配置说明。
- 投稿与邮件订阅演示、隐私/条款/奖励规则、存储偏好设置。
- Node.js + SQLite API 接入工程：授权优惠导入、演示账户/账本、幂等兑换、带时间窗口的 HMAC 合作方回调。
- OpenZeppelin 签名领奖合约及 Foundry 测试源码；默认暂停，未部署。

## 范围边界

用户已选择“暂无账户，先完成演示与接入接口”。本交付因此使用明确标识的示例优惠、浏览器本地演示账本和演示兑换。

**静态在线预览仅包含前端演示，不托管 Node/SQLite API。** 浏览器账本和后端 API 演示账本彼此独立，前端不会在网络失败时把真实账本替换成本地余额。后续生产前端必须统一到通过认证的服务端账本；不能把 localStorage 作为真实提现依据。

所有示例码均以 DEMO- 开头，不宣称商家合作或实时有效；商家按钮前往其官网。投稿/订阅仅本地保存，不发送。没有真实广告投放或真实 USDT。测试网模块配置完成后由用户钱包发送测试网交易，原商城兑换仍为离线模拟。

原商城钱包连接只用于离线演示填入地址；新增测试网模块独立完成服务端 EOA 钱包签名验证。智能合约钱包登录和嵌入式钱包可按需扩展。社区原离线数据不会自动上传或计入测试积分。

## 文件位置

| 路径 | 用途 |
| --- | --- |
| dist/ | 可独立部署的静态网页与全部交互 |
| dist/config.js | 品牌、Monad 网络、社媒、广告位公共配置 |
| dist/adapters.js | Google 展示广告适配器、Meta/TikTok 能力边界 |
| dist/community.js / community.css | 社区动态、品牌广场、个人空间、通知与资料设置 |
| api/ | 可本地运行的 SQLite 接入工程，独立于静态在线演示 |
| contracts/ | 签名奖励领取合约、编译产物、Foundry 测试源码 |
| tests/ | DOM 交互、账本和回调安全测试 |
| INTEGRATION.md | 广告、优惠源、生产结算接入说明 |

## 后续配置

社媒：在 `dist/config.js` 的 `socials` 中填写各 HTTPS 官方主页，不需要修改组件。真实广告和奖励结算需要按 INTEGRATION.md 完成发布商资质、数据源、身份认证与资金配置，不能仅将 mode 改为 live。
